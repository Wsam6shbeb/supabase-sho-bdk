# اختبارات قاعدة البيانات

## `smoke_lifecycle.sql`
اختبار دخان ذاتي الاحتواء (ينشئ مستخدميه وطلبه ومقدم خدمته بنفسه) **ويتراجع دائماً**: ينتهي بـ `RAISE EXCEPTION`
فلا يُحفظ أي شيء. شغّله في Supabase SQL Editor بعد أي migration.

النتيجة المتوقعة (تظهر كرسالة خطأ مقصودة):

```
RESULT PASS (32 checks, 0 failures)
```

يغطي: منع التلاعب بالصلاحيات (is_admin، حالة الطلب، التقييمات المزيّفة، المحفظة، دفتر الحسابات، الدوال المميّزة، تزوير الإشعارات)،
وفتح المحادثة، والرسائل ومنع التكرار والإشعارات، والاتفاق (العمولة ورفض الموافقة من غير مقدم الخدمة وخصم الرصيد)،
والإتمام والتقييم وسمعة مقدم الخدمة وشاشة "أعمالي"، وفحص الحظر.

إذا ظهر `FAIL` فالرسالة تسرد الفحوصات التي أخفقت.
